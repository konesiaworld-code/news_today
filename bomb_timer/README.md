# 때지의 스탑워치 💣

클래식한 폭탄 모양의 **1시간 타이머** Android 앱 (Flutter).

- 검은 폭탄 몸통의 빨간 7세그먼트 표시창에 남은 시간이 `60:00` 부터 줄어듭니다.
- 작동 중에는 심지에 불꽃이 붙어 **남은 시간만큼 심지가 타들어갑니다.**
- 마지막 10초: 째깍 소리 + 진동 + 화면이 붉게 떨림.
- 0초: 섬광 → 불덩이 → 파편 → **BOOM!** 폭발 연출과 폭발음.
- 폭탄이나 가운데 버튼을 탭하면 점화 / 일시정지, 왼쪽 버튼은 리셋.
- 앱을 내리거나 꺼도 시간은 계속 흐르고, 1시간이 되면 **폭발음 알림**이 옵니다.
- 작동 중에는 화면이 꺼지지 않습니다.
- 아이콘도 불붙은 클래식 폭탄 (기본 · 원형 · 적응형).

## APK 받기 (빌드 없이)
저장소의 `dist/때지의 스탑워치.zip` 을 내려받아 압축을 풀고 휴대폰에 설치합니다
(카카오톡으로 그대로 보낼 수 있음).
Actions 탭 → `폭탄 타이머 APK 빌드` → 최근 실행의 **Artifacts** 에서도 받을 수 있습니다.
(`bomb_timer/` 를 바꿔서 올리면 자동으로 다시 빌드됩니다. *Run workflow* 로 수동 실행도 가능)

## 직접 실행
```
cd bomb_timer
flutter pub get
flutter test
flutter run
```

## 파일
| 경로 | 내용 |
| --- | --- |
| `lib/main.dart` | 화면, 타이머 상태(대기·작동·일시정지·폭발), 저장/복원 |
| `lib/bomb_painter.dart` | 폭탄·심지·불꽃·7세그먼트 표시창 그리기 |
| `lib/explosion.dart` | 폭발 연출 |
| `lib/alarm.dart` | 앱이 뒤에 있을 때 폭발 알림 예약 |
| `tools/make_assets.py` | 아이콘(mipmap, 1024 원본)과 효과음(째깍, 폭발음) 생성 |

아이콘이나 소리를 바꾸려면 `tools/make_assets.py` 를 고친 뒤
`python tools/make_assets.py` (pillow, numpy 필요) 를 실행하세요.
